About

Built because the messenger we grew up with disappeared.

Skype shut down in May 2025, and its replacement was a workplace meeting app. We wanted the messenger back: a contact list, presence, a mood message and a chat window. So we built one.

What Phaze is

Phaze is an independent, open-source messenger. It recreates the feel of classic Skype, with six era themes modelled on releases from 2007 to 2018, and adds things classic Skype didn’t have, like end-to-end encrypted DMs, Spaces for communities, and an import for your old Skype export.

How it works

One Go server handles accounts, message relay and storage. The web app is built with React; Android is a native Kotlin app; the desktop apps wrap the web app. One-to-one DMs are encrypted on your device. Calls currently run on the public Jitsi Meet service, which we say plainly everywhere it matters. Read the security overview.

What we won’t do

No ads, no tracking, no selling data, no paywalled chat. If you’d rather not trust our server, the code is MIT-licensed and you can run your own.

Get involved

The repository is at github.com/jakes1345/phazechat.world. Bug reports are the most useful thing you can send. Phaze is not affiliated with Microsoft or Skype.
