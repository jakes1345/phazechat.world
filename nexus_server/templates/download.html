Pick your platform

The desktop apps are new and still in beta. If one won’t connect, the web app always will.

Web app Recommended

Chrome, Edge, Firefox or Safari on Windows, Mac, Linux and ChromeOS. Every feature and every era theme.

Open in your browser

Android

Android 8.0 or later. DMs, group chats, calls, Spaces and push notifications. Installed from an APK, not the Play Store.

Download APK

Your phone will ask you to allow installs from your browser the first time.

iPhone, iPad & Mac

There’s no native Apple app. Open the web app in Safari, then tap Share → Add to Home Screen (or File → Add to Dock on a Mac).

Open in Safari

Windows Beta

Windows 10 or 11, 64-bit. An installer that puts the web app in its own desktop window.

Download for Windows

From the latest GitHub release.

Linux Beta

A single x86-64 binary. Needs GTK 3 and WebKitGTK 4.1. Make it executable with chmod +x Phaze-linux-amd64, then run it.

Download for Linux

From the latest GitHub release.

Source & self-hosting

Every client and the server are MIT-licensed. Build them yourself, or run your own server from the Docker image.

System requirements

Web

  • A current version of Chrome, Edge, Firefox or Safari
  • Camera and microphone permission for calls
  • Installable as an app from the browser menu

Android

  • Android 8.0 (API 26) or later
  • About 50 MB for the download
  • Camera, microphone and notification permissions

Desktop (beta)

  • Windows 10 or 11, 64-bit
  • Linux x86-64 with GTK 3 and WebKitGTK 4.1
  • No macOS build. Use the web app on a Mac

Downloads for Windows and Linux come straight from the project’s GitHub releases. The Android APK is served from this site.
