# Skype 7.x ("Skype Classic") (2014-2018)

## At a glance

- Skype 7.0 launched with a redesign featuring chat bubbles in varying shades of soft blue, rounded contact avatars, and better notifications [7].
- As of version 7.0, H.264 was used for both group and one-on-one video chat, at standard definition, 720p, and 1080p high-definition [1].
- Skype version 7.0 ("Skype classic") was announced to stop functioning after September 1, 2018; users needed to update to version 8.0 to keep using Skype after the cutoff [4].

## Changelog and platform

- As of version 7.0, H.264 was used for both group and one-on-one video chat [1].
- On 11 November 2014, Microsoft announced that in 2015 its Lync product would be replaced by Skype for Business, combining the features of Lync and the consumer Skype software [1].
- Skype's WiFi service (paid hotspot access) was retired globally on 31 March 2017; Microsoft's stated reason was to "better focus our efforts on bringing you the best possible experience through our core Skype features" [2].
- The Skype WiFi service "became non-functional from 31 March 2017" [1].
- Skype's third-party Extras program for developers was closed in 2009 (pre-dating the 7.x era), with Antoine Bertout stating "simply not enough people were using them to justify our continued support"; existing Extras remained available via the Extras Manager but no new ones were accepted [3]. This is background context predating 7.x, included to show the Extras program was already gone by the time Skype 7 shipped.
- Skype version 7.0 (aka "Skype classic") was announced to no longer function after September 1, 2018 [4].
- Skype 7.0/Classic would continue to work until that cutoff date; afterwards users needed to update to version 8.0 to keep using Skype [4]. (partly sourced — a critique cross-check found an independent source reporting the actual desktop cutoff was later delayed to November 1, 2018, which this pass did not itself verify.)
- Windows installer builds documented on an Internet Archive file listing include SkypeSetup 7.36.0.101.exe, 7.36.0.150.exe, 7.40.0.103.exe, 7.40.0.104.exe, 7.40.0.151.exe, and 7.41.0.101.exe [5].

## Settings and UI

- Skype 7.0's desktop redesign introduced chat bubbles in varying shades of soft blue, rounded contact avatars, and better notifications [7].
- In the Skype 7 chat window, shared image files can be viewed instantly in-line once downloaded, instead of requiring a click on an icon to preview them [7].
- The Windows version of Skype 7 increased the spacing between the contacts list and the chat window compared to prior versions [7].
- Skype 7 shows message previews in the contacts/chat list for unread messages, so users can see content without switching between chats [7].
- Skype 7's redesign made it easier to have chat conversations alongside a video or voice call [7].
- Skype 7.0.0.102 for Windows (released 5 December 2014) added "friendlier interface for touchscreen devices," letting users scroll, call, and view messages with a touch of the screen surface [8].
- Skype 7.0.0.102 added a setting to hide or show big emoticons of the user's own choosing [8].
- In Skype 7.0.0.102, the View menu item "Standard view mode" was renamed to "Showing a single window" [8].
- In Skype 7.0.0.102, the View menu item "Simple List" was renamed to "Compact sidebar" [8].
- Skype 7.0.0.102 updated the overall color scheme and updated the compact interface mode [8].
- Skype 7.0.0.102's chat compact-view option string changed from "Open a new window when I receive a new message in Compact view" to "...in Split Window View" [8].
- Skype 7.0.0.102 changed the chat input SMS field from a "Send SMS" button label to inline placeholder text "Type an SMS here" [8].
- Skype 7.0.0.102 added support for sending/receiving images even when the recipient/sender is offline [8].
- Skype 7.0.0.102 added an option, when sending multiple files, for the user to "show all" files or only some of them [8].

## Presence and messaging

- Skype allows users to remove or edit individual messages during one hour after sending, affecting both messages already received by chat partners and those not yet delivered [11].
- Skype's emoticon set includes about 254 emoticons, displayed either statically or animated, plus hidden emoticons, 241 flag emoticons, and 63 other emoticons [11].
- Skype supports group text chat with an interface similar to IRC with up to 150 people [11]. (partly sourced — this figure is undated in the source and not confirmed as specific to the 7.x client itself.)
- Skype group chats have Creator/Moderator and ordinary User roles; only the group's Creator/Moderator (or an Admin) can remove members, and there is no UI button to promote someone to Administrator — a chat command is required [12].
- To promote a member to Administrator, the group Moderator types the chat command "/setrole [SkypeName] Admin"; the new admin can then also remove members and add further Administrators [12].
- The "/showmembers" chat command lists who a group's Users and Admins are [12].
- To target a contact with a role command, a user finds their unique, space-free "Skype Name" (distinct from the display name) via right-click > View Profile [12].
- Skype file transfers were limited to 100MB per file, as reported in May 2016 [13].
- Skype later raised the file-sharing limit for files, photos, and videos to 300MB, per a Windows Central headline [14].
- Read receipts were not part of Skype in the 7.x era; they were first introduced in a Skype Insider Preview build in September 2018, after the 7.x/8.x transition [15].
- Since Skype 4, the "Not Available" status was supported; it was removed in Skype 5 [11]. This predates 7.x and establishes context for the status list carried forward.
- Skype's "SkypeMe!" presence indicator, which invited calls from strangers, was hidden from selection starting with Skype 4 and removed completely in Skype 5, so it was not present by the 7.x era (partly sourced — the exact wording of the removal timeline was drawn from a nearby but separately-quoted sentence on the same page) [11].
- Skype 5 and above display other users' "Not Available" status as "Away" [11].

## Calling and notifications

- As of version 7.0, H.264 was used for both group and one-on-one video chat, at standard definition, 720p, and 1080p high-definition [1]. (partly sourced — an independent skeptic check found only tangential corroborating sources; no independent non-Wikipedia source directly confirmed the "as of version 7.0" dating or the SD/720p/1080p tiering.)
- Skype supported conference calls, video chats, and screen sharing between 25 people at a time for free, which then increased to 50 on 5 April 2019 [1].
- On April 28, 2014 (shortly before Skype 7.0's later-2014 launch), Skype made group video calling free again after it had been a paid feature since early 2011; users could connect with up to nine other people, and screen sharing was included, initially on desktop and Xbox One only, not mobile [16].
- Group video calls had become a paid feature in early 2011, just before Skype was purchased by Microsoft for more than $8 billion, before being made free again in April 2014 [16].
- The Online Number (a.k.a. SkypeIn) service allowed Skype users to receive calls on their computers dialed by conventional phone subscribers to a local Skype phone number [1].
- Existing Skype Credit balance for outgoing phone calls can be used via a Skype Dial Pad web application [1].
- Skype added built-in call recording on September 4, 2018 (in the 8.x era, just after the 7.x era ended): during a call, users click the plus sign in the lower right and select "Start recording," and recordings are stored as MP4 files online for up to 30 days for participants to save or share [17].
- At the September 2018 call-recording launch, the feature was available on every platform except Windows 10, with Microsoft saying Windows 10 support would follow within weeks [17].
- When call recording starts, all participants receive a banner notification stating the call is being recorded, and Microsoft recommended users verbally inform others they are recording for consent-law reasons [17].
- Before Skype's native call recording, users relied on third-party applications such as MP3 Skype Recorder to record calls, since the standard consumer Skype app lacked built-in recording throughout the 7.x era [17].

- The claim that Microsoft forcibly updated all remaining Skype 7.x versions (including 7.40/7.41) to Skype 8 beginning February 1, 2019 was checked against the same archive.org item and found NOT SUPPORTED — no such text exists on that page.
- The claim that Microsoft shut down third-party access to Skype's Desktop API at the end of 2013, retaining call recording and hardware-compatibility features after backlash, was checked against the cited PCWorld URL and found NOT SUPPORTED — that page contains only the 2009 Extras-program-closure story, not any 2013 Desktop API narrative.
- The Skype 7.0/Classic September 1, 2018 cutoff claim [4] was independently checked against gHacks and CONFIRMED; the same skeptic check noted that other independent sources report the actual desktop cutoff was later delayed to November 1, 2018 — a detail not captured by the TechCrunch source used here, though it does not contradict the original announcement.
- The 25→50 group-call participant cap increase (5 April 2019) [1] was independently confirmed by MacRumors and other outlets.
- The April 28, 2014 free group-video-calling relaunch [16] was independently confirmed by Engadget; participant-cap figures varied slightly by outlet (nine vs. ten on PC/Mac, four on Xbox One), so "nine other people" is roughly but not exactly consistent across sources.
- The 100MB file-transfer limit (May 2016) [13] was independently confirmed by Windows Report, including the exact error message "not sent - file is larger than 100.0 MB."
- The 300MB file-sharing limit [14] was independently confirmed by 9to5Mac, dated to July 2016.
- The Skype WiFi shutdown date and rationale [2] were independently confirmed by SlashGear, which also noted Skype Credit could be repurposed for calling after shutdown.
- The September 2018 call-recording feature [17] was independently confirmed by gHacks (MP4 format, 30-day availability, plus-icon flow); that check did not explicitly confirm the Windows-10-excluded-at-launch detail but did not contradict it either.

## Differences from the earlier research docs — from the critique's contradictions list

- Prior research.md described the 300MB file-sharing limit as "raised to 300MB (July 2016) — briefly capped at 100MB earlier the same year," with no WiFi/Extras/call-recording tie-in and no note that H.264 covered 720p/1080p specifically. This pass's Wikipedia evidence adds the fuller quote: H.264 was used "at standard definition, 720p, and 1080p high-definition" — a resolution-tier detail absent from prior docs [1].
- Prior docs framed the @mentions Skype-7-vs-8 dating question as unresolved, gating `mentions` to Skype 8 only. None of this pass's verified claims address @mentions, so this remains unresolved — the new evidence did not settle it.
- Prior docs (skype-era-gaps.md) list Skype Translator as an unimplemented-but-sourced 7.x feature; this pass's verified-claims batch contains zero claims about Skype Translator, so that gap persists untouched.
- Prior research.md stated the P2P-to-Azure migration (completed April 2017) was "approximately when temporary (30-day) server-side storage of voice messages, video messages, file attachments and call recordings began." This pass's evidence narrows that: the 30-day server-side MP4 storage policy is documented specifically for call recordings, and that feature shipped in September 2018 (8.x era) — a year after the April 2017 migration. Research.md's phrasing that 30-day call-recording storage "began" around April 2017 is NOT supported by this pass's evidence, which dates the call-recording feature and its storage policy to September 2018, not April 2017 [17].
- Prior docs described Skype Wi-Fi only as "paid hotspot access, discontinued 2017," with no exact date or rationale. This pass pins the exact date (31 March 2017) and Microsoft's stated rationale, quoted verbatim [2].
- Prior docs (themes.ts/research.md) placed read receipts as an "8.0, shipped over summer 2018" feature with no specific date. This pass dates it more precisely to a September 2018 Insider Preview build rollout — September is early autumn, not summer, a minor refinement [15].
