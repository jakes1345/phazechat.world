# Skype 4.x (2009-2010)

## At a glance
- Skype for Windows 4.0 launched February 3, 2009 [1]; a Wikipedia image caption dates the release to 2009, consistent with this [3].
- Skype 4.2.0.158 for Windows was released April 8, 2010 [2].
- The interface was overhauled from the 3.8 predecessor, replacing the previous columnar window layout with a "spacious, quasi-rectangular and dual-paned" main window [8].
- Version 4.2 was the last of the 4.x series before Skype 5.0 (partly sourced) [11].

## Changelog and platform
- Skype 4.0 introduced a new bandwidth manager described as continually delivering "a quality video calling experience, even on a low bandwidth connection" [1].
- Skype 4.0 added a guided setup flow: new users are walked through a "one, two, three process" to download Skype and then test microphone, webcam, headset, and audio quality components [1].
- Skype 4.0 included a "Smart Help" feature that "flags problems and helps correct sound issues during a call proactively" [1].
- Skype 4.0 introduced a "Conversations" tab described as making "it easy to keep track of multiple conversations in one place" [1].
- Skype 4.2 fixed an issue where some users, after upgrading from 4.1, were notified of old authorization requests [2].
- Skype 4.2 had a known issue running Cyberlink YouCam video decoration software [2].
- Skype 4.2 had a known issue: Screen Sharing from Skype 4.2 to Skype 4.0 or lower did not show video to the receiver if the receiver's computer had a Pentium 4 or Pentium 3 processor [2].
- Skype 4.2 had a known issue where, in some rare cases, sending video from a Microsoft LifeCam VX-3000 caused the local preview to freeze, though the other side still received video normally; Skype 4.2 also had known issues calling Asus Videophone users (partly sourced) [2].
- Skype 4.2 (2010) supported the ability to transfer an incoming call to a different user, and was the last of the 4.x series before Skype 5.0 (partly sourced; the same tertiary source's HD-video claim for 4.2 could not be corroborated — see Refuted/unresolved below) [11].
- Skype Chat Support (live chat help) was a premium feature available to Skype Premium and some other paid users (undated source) [3].

## Settings and UI
- The redesigned Skype 4.0 main window used a dual-pane layout: the left pane shows the contact list, the right pane shows detail info and communications history for the selected contact [8].
- Skype 4.0 introduced a "conversation" concept covering all communication types with a contact; a tab adjacent to the Contacts list tab shows all recent conversations for easy resumption [8].
- Skype 4.0 added a button in the upper-right corner of the main window (next to minimize/maximize/close) that detaches the Conversations window, allowing a separate chat window per conversation [8].
- Skype 4.0's system tray icon indicates the number of missed events (missed call, voicemail, or IM); clicking the icon pops up a stacked list showing what each event was [8].
- In Skype 4.0, a Video Call button appears alongside the Call button for each contact, letting users start a call with video from the outset [8].
- In Skype 4.0, audio settings can be accessed at any time from the Call menu, not only while in an active call — a change from prior versions [8].
- Skype 4.1 (2009) call-transfer and last-4.x-release positioning are corroborated for 4.2 (partly sourced) [11]; the claim that Skype 4.1 specifically introduced screen sharing could not be confirmed (see Refuted/unresolved below).

## Presence and messaging
- Since Skype 4, the "Not Available" presence status is supported; it was removed in Skype 5 [4].
- The "SkypeMe!" status was hidden from being selectable starting with Skype version 4, and removed completely in version 5 [4].
- Skype supports sending about 254 emoticons, displayed either statically or animated (undated) [4].
- Presence status vocabulary described for Skype generally (undated, not version-specific) [5]:
  - Online: set automatically by default; friends can contact the user in any way.
  - Offline: shown automatically when Skype is closed, or chosen manually; the user cannot receive calls or instant messages while offline.
  - Away: indicates the user "went away from the computer and most likely will not answer... shortly"; calls/messages can still be sent and notifications include sound.
  - Do Not Disturb: the user is online but does not want to be disturbed; messages or calls arrive without sound notification.
  - Invisible: uses the same icon as Offline, so a contact cannot tell whether the user is genuinely offline or set to invisible.
  - Blocked: shown to users the account owner has added to their block list; blocked contacts see the blocker as Offline.
  - Unauthorized: applies to a user who has not added the account owner to their contact list or shared contact information.
  - Forwarding: the user is Offline but has set up call forwarding, so calls still reach them.
  - Connecting: the only animated presence icon; shown when Skype cannot connect to the internet, and normally shown only for one's own status.
  - Away status can auto-activate after a configurable idle timer, described as set via Tools > Settings > General tab, "Show me as Away when I've been inactive for [x] minutes" (partly sourced; path description is low-confidence/undated) [5].
- Chat text commands documented (undated, and the source notes not all commands are supported in all Skype versions) [6]:
  - `/add username(s)` adds specified Skype users to a chat; multiple usernames can be separated by spaces; applies to P2P and cloud chat types.
  - `/kick` excludes a specified user from the chat (they can rejoin); `/kickban` removes a user and deprives them of the right to return.
  - `/get role` displays the current user's role in the chat, as set via `/setrole`; applies to P2P and cloud chat types.
  - `/history` loads the entire correspondence history in the active chat window.
  - `/get masters`, `/get helpers`, `/get listeners` display lists of users holding those chat roles (helpers/listeners scoped to P2P chat type).
  - `/set allowlist` and `/set banlist` manage which users may join a chat (prefixing a username with "+" grants trust, "-" removes it) or are barred from it.

## Calling and notifications
- Skype 4.0's redesigned interface added "a big green video call button" alongside the Call button for each contact, putting video calling front and center [7].
- Skype 4.0 offered picture-in-picture video during calls, letting users move the self-view thumbnail around the window [7].
- Skype 4.0 beta supported up to 25 participants in a voice-only group call, but remained "limited to one-to-one video chats" for video [7]. (The skeptic pass could not independently corroborate this specific 25-participant figure elsewhere — treat the number as sourced to TechCrunch alone.)
- Skype's president stated the prior UI "was purpose-built for voice," explaining the shift in emphasis toward video/visual communication in the 4.0 redesign [7].
- Skype 4.0 let users place SkypeOut calls or send texts to domestic or international landlines and mobiles, or purchase a SkypeIn phone number to receive calls and voicemail from phones [8].
- Skype 4.0 used a bandwidth manager "to keep the audio/visual quality as high as possible in situations where connection bandwidth is limited or suddenly degrades" [8].
- Skype 2.0 and later (a range covering the 4.x line) supported Skype-to-Skype video calling between two parties on Windows, Mac OS X, and Linux [4].
- Group video calling (multi-party video) was not introduced until Skype 5, meaning Skype 4.x's group calls remained voice-only, with video limited to two parties — consistent with the TechCrunch 4.0-beta reporting above [4][7].
- Screen sharing was originally a premium feature; group video calls and screen sharing were made free together in "summer 2014," implying screen sharing was not a free feature during the 2009-2010 Skype 4.x era (partly sourced — the specific "up to 10 other people" cap phrasing was not found verbatim on the current page) [4].
- SkypeOut allowed calling landline and mobile phone numbers, including international numbers, using prepaid Skype Credit or a calling subscription [4].
- Skype Number (today's name) was "previously called SkypeIn and Online Number" (partly sourced; the specific claim that the SkypeIn name was used "until 2010" was not found verbatim on the current page) [4].

## Refuted or unresolved — from the skeptic sample
- NOT CONFIRMED: "Skype 4.1 was launched in 2009 and introduced the concept of screen sharing" — the cited page (chat4o.com) does not actually contain this statement; the claim did not survive verification [11].
- NOT CONFIRMED: "Skype for Windows 4.2 supported HD (720p) video calling at up to 22 fps using two Skype-certified HD webcams with an embedded H.264 processor" — the current Wikipedia List of Skype features page contains no such text; instead it attributes 720p support to "Skype 3.6 and later" generally, with no mention of 4.2, 22 fps, or certified webcams [4].
- NOT CONFIRMED: "Skype 4.2 used H.264 in webcams with embedded processors, with legacy VP7 (CPU-side) or VP8 as alternatives" — not found on the cited Wikipedia page, which instead credits an H.264-for-VP8 codec change to Skype 5.8/5.5, not 4.2 [4].
- NOT CONFIRMED: "As of June 30, 2010, Skype had 124 million average monthly connected users and 8.1 million paying users, up from 91 million and 6.6 million in H2 2009" — no such figures appear on the current Wikipedia List of Skype features page [4].
- UNRESOLVED (per skeptic re-check): the chat4o.com tertiary source's claim that Skype 4.2 supported HD video calls is called into doubt by the oldversion.com contemporaneous 4.2.0.158 release-notes/known-issues page, which lists fixes and hardware bugs but never mentions HD video support — an absence-of-mention rather than an explicit denial, but it weighs against the HD claim [2][11].
- UNRESOLVED: the exact 25-participant voice group-call cap is sourced to TechCrunch's 4.0-beta coverage only; no independent source confirms or contradicts this number for the shipped 4.0 or for 4.2.
- UNRESOLVED: Skype 4.2.0.158's April 8, 2010 release date is sourced to oldversion.com only; no independent source found to corroborate or contradict it.
- UNRESOLVED: the "Not Available" and "SkypeMe!" version-4-introduced/version-5-removed dating (Wikipedia) is neither confirmed nor contradicted by skaip.org's status list, which describes Online/Away/DND/Invisible/Offline/Blocked/Unauthorized/Forwarding/Connecting but does not mention "Not Available" or "SkypeMe!" at all.
- UNRESOLVED: whether screen sharing was a premium/paid, participant-capped feature specifically during the 4.x era (2009-2010) is asserted only by the Wikipedia List of Skype features page; the chat4o.com 4.2 feature page is silent on pricing and participant limits for screen sharing.

## Differences from the earlier research docs — from the critique's contradictions list
- Prior docs treat screen_share as simply "present from Skype 4" with no pricing caveat. New evidence indicates screen sharing was originally a premium (paid) feature limited to sharing with up to 10 people, only becoming free (bundled with free group video) in summer 2014 — meaning it likely remained a paid/limited feature through the whole 4.x era, a nuance the earlier docs and themes.ts gating omit (partly sourced) [4].
- Prior docs note group calling existed since Skype 2.x and place group video at Skype 5, but do not cite a specific voice-call participant ceiling tied to the 4.0 release. New evidence adds that the Skype 4.0 beta specifically supported up to 25 participants in a voice-only group call, with video remaining strictly one-to-one [7].
- Prior docs (skype-era-gaps.md) note "SkypeMe!" hidden at v4 / removed at v5. New evidence confirms this and independently surfaces a second, previously undocumented status with the same v4-introduced / v5-removed lifecycle: the "Not Available" status [4].
- Prior docs (research.md) list 4.2 (2010) additions as Skype Access, call transfer, Call Quality Indicator, and better Windows 7 taskbar integration — with no HD video call claim. A tertiary source claims 4.2 also added HD video support, but this could not be corroborated by the contemporaneous oldversion.com 4.2 changelog and is not confirmed on the cited Wikipedia page either — it should stay excluded from confirmed facts, consistent with the prior docs' omission.
- Prior docs' screen_share era-gating (present from Skype 4, ungated) should, per the new pricing evidence, be understood as a paid/limited capability rather than a freely available one, if and when it is ever implemented in the app.
